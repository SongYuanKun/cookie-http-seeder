# Cookie HTTP Seeder v0.5.0

Chrome logs in normally; Cookie HTTP Seeder transfers explicitly authorized, URL-scoped cookies to your HTTP crawler and records the crawler's validation result.

## Highlights

- Persistent login incidents with acknowledge, snooze and recovery history.
- Version-bound crawler feedback, durable feedback outbox, and `consume`, `consumer-status`, `consumer-flush` commands.
- Unified extension dashboard and optional metadata-only client heartbeat, disabled by default.
- Modular receiver and extension implementation; Python 3.11+, no runtime third-party dependencies.

## Install and upgrade

Download the Python wheel, extension ZIP and `SHA256SUMS` from this release. Verify the SHA256 hashes before installing. Install the wheel into your existing virtual environment with `python -m pip install --no-deps --upgrade cookie_http_seeder-0.5.0-py3-none-any.whl`.

Back up the receiver's data directory before updating its existing environment. Update extension code at its original loading path and explicitly reload it in `chrome://extensions`; retain the original profile, endpoint, token, sender tag and local consent. Existing heartbeat and routine settings are preserved.

See [quick start](https://github.com/SongYuanKun/cookie-http-seeder/blob/v0.5.0/README.md), [client upgrade](https://github.com/SongYuanKun/cookie-http-seeder/blob/v0.5.0/docs/client-upgrade.md), and [crawler integration](https://github.com/SongYuanKun/cookie-http-seeder/blob/v0.5.0/docs/consumer-recovery.md).

## Scope

Sender tags group storage; they do not provide separate authorization. The crawler must define a meaningful site-specific login validator. Successful cookie transfer or HTTP 200 alone does not prove login validity. Automatic login, CAPTCHA solving and full browser-profile transfer are outside this release.

CI builds and checks the installed package on Linux, Windows and macOS. Browser acceptance records describe the exact browser/profile and steps exercised; platform CI does not imply every site's authentication works across devices.
