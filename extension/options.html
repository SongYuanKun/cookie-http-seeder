Cookie HTTP Seeder

只同步明确授权的非分区 Cookie；不读取 localStorage，不自动登录，登录有效性由爬虫反馈，不主动请求目标网站。

1. 连接接收端

不同标签分别保存；相同标签共用一份数据。default 使用旧数据区域。标签不是密码或权限边界；更换后需重新授权，不会自动迁移或删除旧数据。
远程必须 HTTPS；HTTP 仅限 localhost / 127.0.0.1，可通过 SSH 转发。更换地址或 Token 后需重新授权来源。
请配置连接。

2. 管理来源

配置来自接收端，但不会自动获得浏览器权限。授权后才会读取对应域名。修改或删除来源会清空它的旧快照。“仅授权”不清空快照；“撤销本机授权”只停止本机同步，不删除接收端数据。

来源域名 / 固定输出目标 URL状态操作
包含这些域名及子域名。需要父域 Cookie 时显式加入父域；不要加入公共后缀。国际化域名使用 punycode。

3. 同步状态与诊断

传输状态、数据新鲜度、爬虫反馈分别展示。最多尝试 5 次；鉴权/授权错误需手动修复后再推送。队列不保存 Cookie。



4. 配置导入 / 导出


只包含网站配置，不包含接收端地址、Token 或 Cookie。导入为全量替换，会清空被删除或修改来源的旧快照。目标 URL 请勿包含秘密。
