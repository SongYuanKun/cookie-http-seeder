# Support / 使用支持

Start with the [quick start](README.md), [onboarding example](docs/onboarding.md), [crawler integration](docs/consumer-recovery.md), and [client upgrade](docs/client-upgrade.md).

安装或使用问题先查看快速开始、接入案例和客户端升级说明。仍有问题时，在 [GitHub Issues](https://github.com/SongYuanKun/cookie-http-seeder/issues/new/choose) 选择 Bug report、Feature request 或 Usage feedback。

Include the receiver/extension version, operating system, Python/Chrome version, installation method, expected behavior and a minimal reproducible example. Review any diagnostic output before posting; use synthetic domain names and cookie values in reproductions.

不要提交 Cookie、Token、webhook、完整浏览器配置、登录页面正文或带凭据的 URL。不要将整个数据目录或浏览器 storage 导出作为附件。安全问题按 [SECURITY.md](SECURITY.md) 私下报告。

This is a volunteer-maintained project. There is no guaranteed response time or commercial support agreement. Reproducible reports and focused pull requests help maintainers investigate.

项目路线图见 [ROADMAP.md](ROADMAP.md)。真实使用反馈可以说明接入的爬虫类型、遇到的问题和已经解决的步骤；公开记录应完成脱敏，维护者不会把模拟测试或自己的使用记录标记为独立用户反馈。
